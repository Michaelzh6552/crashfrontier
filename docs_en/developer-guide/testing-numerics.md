# Test strategy and numerical conventions

Tests live in `tests/`, pytest, `testpaths=["tests"]`. They **do not read**
the repository `DATA/`. Synthetic data is generated by `tests/synthetic.py`
and `conftest.py` under `tmp_path`.

## Synthetic market

`make_option_rows`: three dates (2021-07-21/22/28), expiries 7/14/30 days,
AM/PM pair at 30 days, Black-76 $\sigma=0.18$, spread $0.0005F$,
`strike_price×1000`, `volume` 10 for $x\ge 0.75$. Directory variants cover
uppercase semicolon, `YYYYMMDD`+gz, DATE9 split, stata, parquet, and a pure
DataFrame.

`synthetic_quotes(nodes, weights)`: atomic-distribution prices, default
strike grid, `spread` added on the normalised call.
`true_targets(..., gamma)` gives closed-form $(p,L,s)$ or $(q,\ell,s)$.

`scenarios(K)`: `atom_at_k` / `atom_below_k` / `atom_above_k` / `far_tail` /
`bimodal`. LP runs all five; physical main tests use `bimodal` and
`far_tail`.

## Numerical tolerances

| Object | Tolerance | Source |
|---|---|---|
| data-variant `norm_*` | $10^{-9}$ | `test_dataset.py` |
| γ=0 truth vs marginals | $2\cdot10^{-7}$ | `test_lp.py` |
| LP `duality_gap` | $10^{-9}$ | same |
| certificate cost identity | $10^{-8}$ | `test_certificates.py` |
| transformed area vs quad | $10^{-8}$ | `test_geometry.py` |
| hull `max_gap` | $10^{-8}$ | `test_hull.py` |
| physical targets contain truth | $2\cdot10^{-6}$ | `test_gamma*.py` |
| physical depth contains truth | $2\cdot10^{-5}$ | synthetic truth check; solver/inner reconciliation has a separate $5\cdot10^{-3}$ guard |
| cone violation | $10^{-6}$ | `ConicSettings.violation_tolerance` |
| γ=2 unbounded `prob_lo` | $<10^{-3}$ | `test_unbounded_cap_sends_prob_lo_to_zero` |
| nested γ=0 area monotone | $10^{-10}$ / $10^{-12}$ | `test_frontier.py` |
| nested γ>0 outer containment | $5\cdot10^{-6}$ | same |
| physical half-planes vs inner | $5\cdot10^{-3}$ | coarser grid |
| parallel series summaries | $10^{-9}$ (drop elapsed) | `test_series.py` |

Before changing a tolerance, check whether the matching test is locking
behaviour, rather than “wider is safer”.

## Solver numerical behaviour

**HiGHS**: occasional `status=4` / Unknown → `highs-ipm`. Both fail →
`SupportResult.success=False` → `SolverFailure`. Solutions can still be
rejected on residuals and $\|x\|_\infty\le 10^6$ even when the solver reports
success.

**Duals**: the $\partial\mathrm{fun}/\partial b$ sign is required. When
writing new certificates or printing λ, check
`test_linprog_marginals_match_hand_example`.

**CLARABEL**: `OPTIMAL_INACCURATE` is common. Rescue ladder:
[physical.md](physical.md). Uncertified → `ok=False`; `compute_frontier`
then raises `InfeasibleCrossSectionError` at feasibility or later
`SolverFailure`.

**Depth bisection**: direct min/max can hit `InsufficientProgress` on the
`depth=0` boundary. Bisection replaces “optimal” with feasibility.
`solver_error` must not shrink the interval.

**Depth scaling**: the direct physical depth objective uses a 100× scale and
divides the result back to depth units. Physical support solves normalize an
arbitrary direction by `max(||u||∞, 1)` and rescale the returned value; the
unit coordinate directions used for marginal probability and loss bounds are
unchanged by that normalization.

**Boundary rounding**: strikes and $K$ are `round(..., 12)` then unique.
Compare $K$ at `atol=5e-12`. Quote-activated cells use
`b_j ≥ k_i - 1e-11`.

## Filters and warnings

`pyproject.toml` and `solve.py` both ignore cvxpy’s inaccurate UserWarning.
Do not write tests that `pytest.raises(UserWarning)` against that message.

## Suggested local commands

```bash
# package tests (do not touch DATA)
pytest -q
pytest tests/test_frontier.py tests/test_lp.py tests/test_gamma2.py -q
```

Real-data acceptance is manual/CLI, not pytest. If you run it, use
`crashfrontier` subcommands; tests stay on small synthetic tables and do not
open vendor-scale files.

## Writing new tests

- Synthetic data in `tmp_path` or `synthetic_quotes`; do not commit binary
  fixtures.
- Physical grids use a reduced
  `GridSettings(levels=(16,), max_normalized_gap=0.08)` unless the test is
  about convergence itself.
- When asserting `summary()` key order, copy `test_frontier.SUMMARY_KEYS`.
- Parallel tests assert the worker
  `inspect.getmodule(...).__name__ == "crashfrontier.series"`.
- Infeasibility tests check `InfeasibleCrossSectionError`
  `quote_set/gamma/support_cap/date/expiry`; do not match only a message
  substring.
